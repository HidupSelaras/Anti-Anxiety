Kebijakan Privasi

Kami sangat menghargai privasi Anda. Aplikasi Anti Anxiety dirancang dengan prinsip Privasi Mutlak (Privacy by Design). Berikut adalah penjelasan bagaimana data Anda diperlakukan:

1. Data yang Tersimpan di Perangkat Anda (LocalStorage)

Semua data yang Anda buat di dalam aplikasi ini (termasuk riwayat skala kecemasan, catatan Jurnal CBT, Jurnal Syukur, Jurnal Keberuntungan, pengaturan, dan kontak darurat) hanya disimpan di dalam browser perangkat Anda sendiri.

Kami tidak memiliki server database dan tidak pernah mengirim, mengumpulkan, atau melihat data pribadi Anda. Jika Anda menghapus data penjelajahan (clear browsing data) atau berganti perangkat, data tersebut akan hilang kecuali Anda melakukan Backup ke file JSON.

2. Data Modul Pelepasan Beban (Sangat Privat)

Berbeda dengan jurnal lainnya, tulisan yang Anda masukkan ke dalam Modul Pelepasan Beban (Kejadian, Emosi, Pesan untuk Diri) TIDAK AKAN DISIMPAN SAMA SEKALI. Teks tersebut hanya berada di memori sementara browser dan akan dihapus secara permanen segera setelah Anda menekan tombol "Lepaskan Beban Ini".

3. Tanpa Pelacakan (No Tracking)

Aplikasi ini tidak menggunakan cookie pelacak pihak ketiga, tidak memiliki sistem analitik yang memata-matai perilaku Anda, dan tidak menampilkan iklan. Kami hanya menggunakan pustaka antarmuka (Tailwind CSS, Lucide Icons) serta pustaka grafik (Chart.js) yang diambil langsung dari CDN publik untuk membuat tampilan aplikasi berfungsi dengan baik.

4. Kontrol Penuh Ada di Tangan Anda

Anda memiliki kendali penuh atas data Anda. Melalui menu Pengaturan, Anda dapat mengunduh seluruh data Anda dalam format file .json (Backup) atau menghapus seluruh data aplikasi secara permanen kapan saja.

5. Donasi Pihak Ketiga

Jika Anda memilih untuk memberikan dukungan (donasi) melalui tombol yang tersedia di aplikasi, transaksi tersebut diproses sepenuhnya oleh platform pihak ketiga (seperti Saweria, Trakteer, atau Bank). Kami tidak menyimpan, melihat, atau memiliki akses ke data pembayaran, nomor kartu, atau informasi perbankan Anda. Kebijakan privasi platform tersebut berlaku untuk setiap transaksi.

Terakhir diperbarui: Versi 6.5. Jika ada pertanyaan mengenai privasi, silakan hubungi kami melalui halaman Kontak.
